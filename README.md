### To run this app ###

#### These steps should be followed in the given order ####

#### 1. **git clone https://github.com/sh5800/Codebasics_AI_Cohort_Assignment1.git** ####
#### 2. Open the project inside any code editor (VSCode, Antigravity etc) and inside the terminal run **uv sync ** . ####
#### 3. Now open two terminal windows on your editor and in the first run the command **uv run uvicorn main:app --reload** to start the FastAPI Backend and in the second terminal run the command **uv run streamlit run ui.py** to display the UI generated by Streamlit on Browser. ####
#### 4. Enter the required information and press the **Generate Plan** button to generate your workout plan. ####
